# Loom Extension Images

This folder contains images for the VS Code Marketplace listing.

## Required Images

### loom-icon.png (Required)
- Size: 128x128 pixels
- Format: PNG with transparency
- Purpose: Extension icon shown in marketplace and VS Code sidebar

### Suggested Design
- Dark background (#1a1a2e) matching gallery banner
- Stylized weaving/loom pattern or thread motif
- Clean, modern design visible at small sizes

## Creating the Icon

Options:
1. Use a design tool (Figma, Sketch, etc.)
2. Generate with AI image tools
3. Use an SVG and convert to PNG

The icon should represent "weaving context" - the core metaphor of the Loom extension.
