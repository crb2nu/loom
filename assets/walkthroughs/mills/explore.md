# Explore the Mills tree

Once the HUD URL is set, the **Loom Mills** view in the explorer lights up with six sections:

- **Backlog** — work items the council has queued
- **Pipeline Runs** — implementations in flight
- **Council Runs** — planning/replay history
- **Squads** — configured ensembles
- **Audit Findings** — Loop A artifact judge + Loop B merge attribution
- **Policy Proposals** — adaptive policy diffs awaiting review

Each section lazy-loads on first expand. Click any leaf to open a detail panel with parsed fields and the raw payload. The refresh icon in the view title invalidates everything.
